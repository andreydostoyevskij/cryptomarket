# 💰 CryptoMarket

A simple and responsive cryptocurrency market web app built with **Vanilla JavaScript**, **HTML**, and **CSS**. This project allows users to explore a full list of cryptocurrencies in a dropdown, powered by real-time data from the [CoinMarketCap API](https://coinmarketcap.com/api/). The backend is handled using **Node.js**.

---

## 🚀 Features

- 🔄 Fetches live crypto data from CoinMarketCap API
- 📜 Dropdown list of all available cryptocurrencies
- 📈 Displays selected coin info dynamically
- 💻 Built with plain HTML, CSS, and JavaScript — no frontend frameworks
- 🌐 Backend powered by Node.js

---

## 📦 Tech Stack

- **Frontend:** HTML, CSS, JavaScript (Vanilla)
- **Backend:** Node.js
- **API:** CoinMarketCap API
